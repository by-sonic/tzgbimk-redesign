Железобетонные изделия и товарный бетон для строительства

Бетонные строительные смеси являются уникальным строительным материалом, который применяется с давних времен. Бетонные конструкции ЖБИ имеют высокую прочность, они устойчивы к негативному воздействию окружающей среды и долговечны.

Продукция из известняка

Продуктом дробления осадочной горнопромышленной породы является известняковый щебень, состоящий, главным образом, из кальцита. Известняковый щебень, являющийся одним из востребованных типов щебня, используемого для производства бетона, который в свою очередь идет на изготовление фундаментов зданий и сооружений, применяется в дорожном строительстве. На производство этого бетона идут средние и крупные фракции известнякового щебня. Мелкую фракцию известнякового щебня используют в изготовлении бетона для небольших железобетонных конструкций.

Гравийный щебень

Прочность щебня должна быть в два раза больше, расчетной марки бетона. Производится это по причине того, что проектная прочность бетонных изделий всегда значительно ниже реальной прочности, которую он набирает спустя полгода либо год. Фундаментальность, которой располагают гравии, достаточна для изготовления бетонных смесей вплоть до М-450. Это самый распространенный тип наполнителя. Бетон из него получается значительно дешевле других составов. Для товарного бетона, который используют в индивидуальном строительстве, такая прочность более чем достаточна.

Бетон на щебне из гранита

Гранитный щебень самый твердый бетонный наполнитель. Из смеси на гранитном щебне получаются наиболее надежные конструкции. Дополнительным преимуществом бетона на граните является более высокий показатель плотности, низкое водопоглощение и вследствие – повышенная морозостойкость. Смеси на щебне из гранита классифицируется, в зависимости от размера фракций.

Применение бетона, ЖБИ

Бетон используют для заливки ленточных и монолитных фундаментов, обустройства дорожек. Строительство дорог, по современным ГОСТам должно производиться с использованием только щебня из гранита. ЖБИ используются, например, для промышленного, энергетического, нефтегазового и частного строительства, производят железобетонные изделия для железных дорог.
